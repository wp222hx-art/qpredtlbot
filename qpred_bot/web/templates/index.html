📋 三步开通 新手必读

1
打开 @BotFather → 发送 /newbot → 起个名 → 复制返回的 Token, 填入下方 BOT_TOKEN
2
打开 @userinfobot → 发任意消息 → 复制您的 User ID, 填入 ADMIN_IDS
3
访问 tokenhot.ai 控制台 → 生成 API Key (sk-xxx) → 填入下方 API Key
4
填完后点【💾 保存配置】→【🧪 测试 AI】成功 → 【🚀 启动 Bot】, 然后在 BotFather 里执行 /setprivacy → Disable 让 Bot 能读群消息, 把 Bot 拉进群, 设为管理员即可!
