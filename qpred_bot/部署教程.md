# 🤖 QPred Telegram Bot · 手把手部署教程

> 全程不到 10 分钟,跟着做就能跑起来 🚀

所有 AI 模型走 [tokenhot.ai](https://tokenhot.ai/zh) 统一网关 —— 一个 Key 调遍 GPT / Claude / Gemini / DeepSeek / Grok。

---

## 🎯 第一步:申请三样东西

### 1️⃣ 申请 Telegram Bot Token

1. 在 Telegram 里搜索 **[@BotFather](https://t.me/BotFather)** 并开始对话
2. 发送 `/newbot`
3. 按提示输入:
   - **Bot 名称** (随便取,如 `QPred 客服助手`)
   - **Bot 用户名** (必须以 `bot` 结尾,如 `QPredCSBot`)
4. BotFather 会返回一段 Token,形如:
   ```
   7123456789:AAH-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   ⚠️ **复制保存好,这就是您的 `BOT_TOKEN`**
5. 关键设置:发送 `/setprivacy` → 选您刚创建的 Bot → **Disable**
   > 这一步必须做!不然 Bot 在群里只能看到 @ 它的消息,无法读群聊内容

### 2️⃣ 获取您的 Telegram User ID

1. 搜索 **[@userinfobot](https://t.me/userinfobot)**
2. 发送任意消息(比如 `Hi`)
3. 返回的 `Id` 字段就是您的 User ID,如 `123456789`
4. **复制保存,这是您的 `ADMIN_IDS`**

### 3️⃣ 获取 Tokenhot API Key

1. 打开 [https://api.tokenhot.ai/register](https://api.tokenhot.ai/register) 注册
2. 登录后访问 [https://api.tokenhot.ai/console/token](https://api.tokenhot.ai/console/token)
3. 点【生成 Key】,复制返回的 `sk-xxx...`
4. 充值少量余额(几美元就够测试)

## 🎯 第三步:在面板里完成配置

### 配置面板的 3 个区块:

#### 📲 左上 · Telegram & 平台
| 字段 | 值 |
|---|---|
| **BOT_TOKEN** | 第一步从 BotFather 拿到的 Token |
| **ADMIN_IDS** | 您的 User ID(多个用逗号) |
| **GROUP_CHAT_ID** | 留 `0` 即可(后面在群里发 `/register_group` 自动登记) |
| **群里每条消息都用 AI 回答** | ✅ 勾选 = 全员客服模式 |

→ 点 **【🔍 测试 BOT_TOKEN】**,看到 `✅ Bot 连接成功!` 即配置正确

#### 🧠 右上 · AI(Tokenhot 网关)
| 字段 | 值 |
|---|---|
| **OPENAI_BASE_URL** | `https://api.tokenhot.ai/v1` (默认已填) |
| **API Key** | 第三步从 tokenhot 拿到的 `sk-xxx` |
| **模型** | 推荐 `Claude Sonnet 4.6`(性价比最优) |
| **测试问题** | 随便填(默认即可) |

→ 点 **【🧪 测试 AI】**,看到 `✅ 调用成功!` 并返回 AI 回答即调通

#### 🚀 底部 · 保存 & 运行
1. 点 **【💾 保存配置】** → `✅ 配置已保存到 .env`
2. 点 **【🚀 启动 Bot】** → 状态变成 🟢 运行中
3. 实时日志会显示:
   ```
   🚀 QPred Telegram Bot 启动成功!
   ```

## 🎯 第四步:把 Bot 拉进群,完成上线

### 1. 私聊测试
- 在 Telegram 搜索您的 Bot 用户名 → 点 `START`
- 应该收到欢迎消息 + 您的专属推广链接 ✅

### 2. 拉进群
1. 在目标 Telegram 群里 → 群信息 → 添加成员 → 搜索您的 Bot → 邀请
2. **把 Bot 设为管理员**(必做!),勾选这些权限:
   - ✅ 删除消息(用于反诈/反刷屏)
   - ✅ 封禁成员(用于踢出 CAPTCHA 不通过的用户)
   - ✅ 禁言成员
3. 在群里发 `/register_group`(管理员命令),把该群登记为定时广播目标

### 3. 验证
- 在群里随便发一句话 → Bot 会自动 AI 回复 ✅
- 发 `/predict` → 显示热门预测市场
- 发 `/price` → 显示 JYC 实时行情

## 🛠️ 故障排查

### ❌ 测试 BOT_TOKEN 失败:`Unauthorized`
→ Token 复制错了,或 Token 已被 BotFather 撤销。重新去 BotFather 用 `/mybots` 选 Bot → API Token

### ❌ 测试 AI 失败:`HTTP 401: Invalid token`
→ Tokenhot API Key 错了或余额不足。访问 [tokenhot 控制台](https://api.tokenhot.ai/console/token) 检查

### ❌ Bot 启动后群里没反应
→ 99% 是没设 `/setprivacy → Disable`!重新去 BotFather 设置一下

### ❌ Bot 进群后不能删消息
→ 没把 Bot 设为群管理员,或没勾选"删除消息"权限

### 📜 查看实时日志
- 面板底部 "📜 Bot 实时日志" 自动滚动显示
- 或命令行:`tail -f logs/qpred_bot.log`

## 🎁 进阶玩法

### 切换 AI 模型
随时在面板上选不同模型保存即可,无需重启 Bot:
- 求**省钱** → `gpt-5.4-nano`
- 求**性价比** → `claude-sonnet-4-6`(推荐)
- 求**最强推理** → `o3` / `claude-opus-4-6-thinking`
- 求**响应快** → `gemini-3-flash`

### 关闭"全员客服"模式
不勾选【群里每条消息都用 AI 回答】保存,Bot 只会在以下情况回复:
- 有人 @ 它
- 有人回复它的消息
- 出现客服关键词("怎么"/"如何"/"客服"等)

### 扩展 FAQ 知识库
编辑 `knowledge_base/faq.json` → 在 Bot 私聊发 `/reload_faq` 热加载,无需重启
